# Stakeholder Analysis

| Stakeholder | Primary Need | MVP Interaction |
|---|---|---|
| Athletic Director | Accurate current event operations | Full event management |
| Coaches | Maintain event and participant details | Create/edit/confirm events, manage participants |
| Teachers | Know who will miss class | View event info and students sorted by grade |
| Kitchen Staff | Know names/counts, meals, dietary indicators | View event and participant details |
| Drivers | Know timing, location, vehicle | View event and driver assignment |
| School Administration | Operational visibility | View/manage events under Staff permissions |
| Admin User | Maintain trustworthy system data | Manage users and master data |
| Accountant | Budget visibility | Future enhancement |

## Change Management
- Keep EventFlow simpler than fragmented notes while retaining WhatsApp only as an intentional communication handoff, not the source of truth.
- Train users on a small number of core flows.
- Use realistic pilot events before broad rollout.
- Prioritize mobile usability.
- Route non-critical feedback to Future Roadmap.
