# Project Overview

I am building a portfolio project to help me transition into an **AI Software Implementation Manager** role. The goal is **not** to demonstrate advanced software engineering, but to demonstrate the work of an implementation consultant:

* Requirements gathering
* Business process analysis
* Solution design

* User acceptance testing (UAT)

* AI integration

The application will solve a real operational problem that I currently experience as an **Assistant General Manager and Athletic Director** at an international boarding school.

---

# Project Vision

Build a web application called **EventFlow** (working title).

It will be an **Event Operations Platform** that serves as the **single source of truth** for school events.

The system should eliminate the need to coordinate information through:

* WhatsApp
* Notes
* Email
* Google Calendar
* Memory

Instead, all information should live in one system.

---

# MVP Goals

The first version should accomplish the following:

* Create events
* Edit events
* Cancel events
* Assign multiple staff members
* Assign multiple drivers
* Assign multiple vehicles
* Add and remove students
* Automatically create/update/delete Google Calendar events
* Keep one central database for:

  * Upcoming events
  * Current events
  * Past events

No AI should be included in Version 1.

# Core Workflow

1. User logs in.
2. User creates an event.
3. User assigns:

   * Staff
   * Drivers
   * Vehicles
4. User adds participants.
5. Event remains Draft.
6. Athletic Director changes status to Confirmed.
7. Google Calendar event is automatically created.
8. Future edits automatically update the Calendar event.
9. Cancelling the event removes it from Google Calendar.
10. Completed events remain available for one year before archival.
